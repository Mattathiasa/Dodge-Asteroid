About

Dodge Asteroid is a small arcade game: stay alive as the field fills up. Score comes from time survived and asteroids dodged, and threading a near miss builds a combo multiplier.

It is written in TypeScript and rendered with the Canvas 2D API, with no runtime dependencies. The simulation runs on a fixed timestep, so it behaves identically at any frame rate, and every random value comes from a seeded generator, which makes a whole run reproducible in tests.

Controls — move with the mouse, touch, arrow keys or WASD. P or Esc pauses, R restarts, M mutes.

Built by Mattathias Abraham. Source on GitHub.
